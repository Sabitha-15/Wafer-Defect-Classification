

\# Card E3 – Wafer Defect Classification



\## Project Overview



This project investigates semi-supervised wafer defect classification

using the WM-811K wafer map dataset.



The project is assigned under Track E, Card E3.



\## Objectives



\- Develop a classical machine learning baseline.

\- Implement radial-profile and 2-D CNN models.

\- Investigate spatial attention and model fusion.

\- Evaluate pseudo-labelling for semi-supervised learning.

\- Analyse classification performance and computational cost.



\## Dataset



WM-811K wafer map dataset.



Approved acquisition source:

https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map



Dataset files are not stored in this GitHub repository.
